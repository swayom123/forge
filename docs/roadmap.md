# Roadmap

Phase 1 delivered the service, CLI, persistence, identity scanner, contracts, and tests. Phase 2 adds bounded repository profiling, incremental Python AST indexing, and search. Tasks remain queued without execution.

Phase 3 will add structured issue understanding, acceptance criteria, task decomposition, affected-file estimation, and verification plans using only retrieved index context. Later phases will add isolated worktrees, patch records, sandboxed commands, testing and repair loops, independent review, model routing, and evaluation. No task may be marked complete until implemented verification gates actually run.
